# Code of conduct

PageVet follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful, assume good faith, keep discussion on the work, and don't harass anyone in issues, pull
requests or anywhere else this project lives.

**Reporting.** Report conduct problems privately the same way as security problems: see [SECURITY.md](SECURITY.md).
Reports are read by the maintainer only and handled
in confidence; the maintainer may remove comments or block accounts that break this code.
