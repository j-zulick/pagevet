PageVet 0.2.0 reads more of the pages you point it at, and scans email too.

- **Fetch pages that block plain requests.** `--via auto` tries plain HTTP first, then your own Firecrawl, then your own crawlee-server, and records which one read the page and why it fell back.
- **Check your own list of AI crawlers.** `pagevet-access --crawlers FILE` adds crawlers in the same CSV format as the built-in fourteen, which now live in a data file.
- **Scan an email.** `pagevet message.eml` checks the subject, text, HTML and PDF or Word attachments, with hidden text kept apart from what a reader sees. The field-study explorer now fits phone screens.

**Assets:** the wheel and source archive install PageVet without cloning the repository. `explore.html` is the field-study explorer as one file you can open offline.

All changes and measurements: [CHANGELOG](https://github.com/j-zulick/pagevet/blob/v0.2.0/CHANGELOG.md).
