PageVet 0.4.0 scores what the earlier releases measure, so you can see which pages and sites to fix first.

- **Score pages and sites.** `python -m pagevet.scores` turns PageVet's JSON reports into a page risk score, a site AI visibility score and an opportunity score, each with its reasons; anything without input is reported as not measured.
- **See how your server answers each crawler.** The traffic import now counts 2xx to 5xx responses per AI crawler, and the scores list 4xx and 5xx answers as a gap.
- **Tag AI crawler traffic in OpenSearch.** `python -m pagevet.traffic --opensearch-pipeline` writes an ingest pipeline that labels each log document with the crawler, its group and kind.

**Assets:** the wheel and source archive install PageVet without cloning the repository. `explore.html` is the field-study explorer as one file you can open offline.
