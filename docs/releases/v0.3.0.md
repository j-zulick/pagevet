PageVet 0.3.0 turns one site's crawler access, findings and AI bot traffic into a report you can share.

- **Write an AI visibility report.** `pagevet-access URL --report FILE` saves one self-contained HTML page per site: which AI crawlers may read it, what the server actually serves them, findings, AI share links and `llms.txt`.
- **Import AI bot traffic.** `python -m pagevet.traffic` reads a CSV, an access log or an OpenSearch export and reports AI crawler hits per page; `--updates` shows hits around each content update, labelled a signal, not proof.
- **Check six more AI crawlers.** Search and on-request fetchers from Google, Meta, Amazon and DuckDuckGo join the list, twenty in all.

**Assets:** the wheel and source archive install PageVet without cloning the repository. `explore.html` is the field-study explorer as one file you can open offline.
